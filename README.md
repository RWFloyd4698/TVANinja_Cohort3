# TVA Ninja Cohort 3 - Agentic Workflow Workshop

This repo is the **customer-facing landing page and build kit** for TVA Cohort 3.  
It supports a hands-on workshop where TVA teams build Copilot Studio agents and Power Automate workflows in their own M365 environment.

## What we are doing

1. Building practical, role-based agents for TVA work areas (Transmission, Generation, Nuclear, Finance, IT, CAO).
2. Connecting those agents to governed Power Automate workflows with human approval.
3. Keeping all data and activity in Microsoft 365 (SharePoint, OneDrive, Teams, Outlook, Planner).
4. Using public TVA sources and workshop-safe content only.

## Workshop day overview

| Time block | Session | Outcome |
|---|---|---|
| Block 1 | Kickoff + architecture | Shared understanding of the M365 agentic workflow model |
| Block 2 | Data and environment setup | Participants configure SharePoint/OneDrive/list foundations |
| Block 3 | Agent build labs | Teams build and test role-specific agents |
| Block 4 | Power Automate wiring | Teams connect agent outputs to approval-backed flows |
| Block 5 | Team demos + capstone | Each team shows working agent + workflow + governance path |
