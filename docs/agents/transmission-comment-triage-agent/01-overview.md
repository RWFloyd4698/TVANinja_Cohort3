# Transmission Comment Triage Agent

## Purpose

Customer-facing draft assistant that classifies transmission-related comments and prepares approval-ready response drafts.

## Outcomes

1. Categorize comment type and urgency.
2. Recommend owner and next step.
3. Draft plain-language response for approval.
4. Produce structured JSON for Power Automate.

## Supported cohort teams

- Transmission
- IT
- CAO (HR, community engagement, government relations)

## Boundaries

- Draft only; never auto-send.
- Public source grounding only.
- Human approval required for all outgoing responses.
