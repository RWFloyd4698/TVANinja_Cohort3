# Agent overview: Strategic Alignment Briefing Agent

## Purpose

Translate TVA strategic-plan priorities into concise, audience-specific briefings tied to projects and initiatives.

## Primary users

- Executives and sponsors
- Finance leaders
- Nuclear and generation leaders
- Transmission leadership
- CAO and community/government relations

## Core capabilities

1. Map project narratives to strategic priorities (operational excellence, financial strength, partnerships, innovation, people).
2. Produce role-based briefs (executive, finance, operations, community-facing).
3. Generate speaking points for workshops and steering meetings.

## Boundaries

- Uses only public strategic-plan and TVA website content.
- No internal pipeline, sales, or private communications content.

## Output template

```text
Strategic Alignment Brief
- Audience:
- Priority focus:
- How this aligns to TVA strategic priorities:
- Reliability/affordability implications:
- Recommended next stakeholder message:
- Source references:
```
