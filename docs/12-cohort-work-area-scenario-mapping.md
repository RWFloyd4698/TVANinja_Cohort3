# Cohort work-area scenario mapping

## Scenario map (aligned to roadmap tiers)

| Work area | Primary demo fit | Example prompt |
|---|---|---|
| Nuclear | Strategic Alignment Briefing Agent (Tier A) | "Create a nuclear leadership brief tied to operational excellence and reliability." |
| Finance | Strategic Alignment Briefing Agent (Tier A) + Reliability & Affordability Tradeoff (Tier B) | "Summarize affordability and financial-strength implications for this transmission project." |
| Generation Team A | Transmission Planning Navigator (Tier A) + Generation-Transmission Dependency Agent (Tier C) | "Show project dependencies that could affect generation delivery timing." |
| Generation Team B (Dam Management) | Transmission Planning Navigator (Tier A) + Generation-Transmission Dependency Agent (Tier C) | "Explain how transmission schedule sequencing affects dam-adjacent operations planning." |
| Transmission | Transmission Planning Navigator (Tier A) + Transmission Siting Explainer (Tier B) | "List current project stage and upcoming milestones for each project in Alabama." |
| IT | Transmission Comment Triage Agent (Tier A) + IT Workflow Orchestrator (Tier B) | "Classify and route public comments with SLA and audit trail." |
| CAO (HR + Community + Gov Relations) | Transmission Comment Triage Agent (Tier A) + Community/Gov Relations Hearing Prep (Tier B) | "Draft a community-safe response and an executive talk track for stakeholder meetings." |

## Recommended workshop breakout

1. Tier A first: Transmission + Generation + Finance build headline agents.
2. Tier B next: add role-specific extension packs by function.
3. Tier C optional: advanced scenario design and capstone packaging.
